# daily-skills
日常整理的 Codex Skill 集合。

## Skills

- `skills/feishu-vln-project-summary`：只读遍历飞书 Wiki，筛选端到端 VLN 工作，整理来源、时间和简历素材。
- `skills/resume-overleaf-publish`：修改 LaTeX 简历，编译检查一页排版，并在明确要求时推送到 Overleaf。

## 维护约定

- Canonical remote：`https://github.com/qlsinori/daily-skills.git`
- 所有 Skill 的新增、修改和删除都提交到本仓库并推送到 `main`。
- 修改 Skill 后运行对应的 `quick_validate.py`，确认工作树只包含预期文件，再提交并推送。
