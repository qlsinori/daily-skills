# MapDB 项目开发约束

本文将地图生产工作台历次迭代的共性要求归纳为后续开发约束。适用于 MapDB 云端代码、地图编辑、交互导航及相关测试；具体功能以当前用户请求和现有接口为准，不将历史需求扩展为新的任务。

## 任务范围与独立审查

- 先核实当前代码、运行版本和复现路径，再确定根因及最小修复范围。区分诊断、实现、本地测试和生产发布，不把只读排查变成外部写操作。
- 每次代码修改安排独立 Terra（medium）代理监督：开始时检查需求和风险，结束时审查最终差异及测试结果。审查默认只读，不与实现者同时修改同一文件。
- 审查应关注需求遗漏、数据安全、异常路径、重复逻辑和不必要的兼容层。发现问题后修复并复测；模型不可用或审查未完成时如实报告。
- 保留工作区已有改动。发布前获取最新代码并核对同事提交；有冲突时处理明确的冲突，不用重置、覆盖或强推消除差异。

## 数据与代码安全

- 已有地图原件、地图版本、原始采集数据和备份不得因开发、测试、迁移或清理发布产物而删除。旧包读取后生成新版副本，不原位改写原件。
- 测试使用临时目录、测试夹具或明确隔离的副本。不得对生产地图执行编辑、删除、合并、发布，也不得向真实机器人部署来验证测试。
- 用户明确要求的数据删除或端侧部署，应先解析准确目标、检查保护规则，必要时备份并提供失败回退；不能把某次授权沿用到其他目标。
- 草稿保存与地图发布分离；仅显式发布增加版本。发布前校验应针对当前编辑状态，避免拿旧版本检索索引或旧数据报告成功。
- 代码采用现有项目结构，C++、Python、Bash 遵循 Google 风格与项目规范，前端沿用现有清晰风格。不引入与问题无关的重构、依赖或兼容功能。
- 确有旧数据支持需求时，使用真实格式证据和回归测试约束兼容逻辑；优先复用现有接口与公共组件，不复制一套实现。

## 交互一致性

- 同一参数只有一个明确配置入口。确认弹窗说明对象、影响和下一步，不重复高级参数页的表单。
- 高频编辑操作保持直接可达，按功能分组；不以多一次点击为代价机械折叠工具。图层、标注和底图通过颜色、形状、线型保持辨识度。
- 页面跳转保留地图、版本和当前任务上下文；切换工具应退出前一个临时编辑状态，取消操作不能留下隐式模式。
- 站内提示使用已有统一对话框。浏览器关闭或刷新时的原生离开提醒受浏览器限制，不承诺修改其样式，也不为统一外观取消未保存保护。
- 异步操作显示进度、成功或失败原因，按需要支持取消、重试，避免重复提交。修改参数后提交当前值，而非后台缓存的旧值。
- 与交互导航、地图编辑共用的数据和可视化优先复用已有逻辑；保存后应能重新打开核实，不把临时画布变化视为持久化成功。
- 可视化必须使用当前地图的完整只读场景，不复用编辑器按视口裁剪的实体集合；图层栏只呈现当前上下文，隐藏历史记录不能删除地图或草稿。选中强调属于显示状态，不修改实体尺寸、坐标或数据库；渲染读取不能调用封存操作历史的接口，拖动和创建绑定必须保持原有撤销边界。
- 重复连接同一机器人应合并进行中的请求；打开独立编辑包不隐式同步或替换机器人地图。服务器缓存以机器人、地图及已验证版本隔离，先验证远端元数据，显式重新校验核对内容哈希；损坏缓存不能被标为已校验，也不能通过删除已有版本来修复。
- 机器人文件检查使用已登记连接、固定地图根目录与有界只读接口；不跟随符号链接，不把文件查看、文件下发和启用定位地图绑定为一个操作。版本未提供时明确显示缺失，不从目录名或文件时间猜测。

- 文件浏览采用当前目录分页、可进入子目录的面包屑导航和独立滚动区域；翻页绑定目录版本，切换目标丢弃旧响应，不能用固定总项数截断代替层级浏览。
- 仅有区域实体而缺少轮廓缓存时，从真实几何与当前地图有效坐标元数据补齐只读显示；测试必须检查具体区域绘制，不能把网格或底图的绘制次数当作语义显示成功。
- 描述校验针对当前草稿，按类别名与文字边界检查，不把相似类别或查询命中视为描述合格；进度来自实际服务阶段，取消、切换与失败不展示过期成功。
- 端侧回退绑定目标地图、所选备份和当前目录内容指纹，复用事务安装、锁与失败恢复；保留被替换目录及选中备份，覆盖当前目录大于备份时的空间峰值、并发变化和重复请求。文件恢复不隐式发布草稿或启用机器人定位。

- 回退必须覆盖部署前为空或尚无语义文件的状态。已存在的空备份可作为显式恢复目标，须醒目确认；缺失/不可读备份不能按空处理。仅内部回退路径放行空清单，普通部署仍拒绝空数据，事务日志、安装校验和重复请求须一致支持该状态。

- 跨浏览器、服务和端侧协议的操作编号在服务边界统一解析与规范化，非法输入在 SSH 前拒绝。涉及端侧写入的测试至少贯通真实页面请求、HTTP 路由、服务转换和临时目录协议执行；仅模拟成功响应不足以证明链路正确。覆盖写入后响应丢失并重试，核对事务编号及备份数量不变。
- 回退窗口优先显示目标、来源与结果摘要，路径/指纹/错误细节默认折叠；固定操作区，长文本换行，避免多个弹窗叠加展示。只读检查可取消并丢弃迟到结果，真实写入保持单次提交边界。

- 机器人连接按能力降级：优先使用同一机器人已登记且可连接的 Monitor；SSH 成功须通过实际只读访问验证，只启用文件查看与显式静态地图加载，不伪造实时连接或访问 SSH 端口的 HTTP 接口。静态查看与定位地图分开记录，切换、断开或关闭加载窗口后丢弃迟到结果；缓存仍按机器人身份和地图版本隔离。实时控制提交时再次检查连接能力，不能只依赖按钮禁用；旧 Monitor 列表请求不得重新启用 SSH 模式下的定位控件。

- 空间索引、绘制缓存和关系端点回退按创建它们的画布/语义实例归属，不能仅用全局活动状态或项目编号判断；同项目的局部编辑视口也不能替代完整可视化场景。缓存轮廓与底图使用不同像素坐标帧时，在只读显示阶段依据分辨率和原点转换，不能改写持久几何。语义显示测试须在主编辑器已安装索引时验证实际绘制或像素变化，而非仅检查传入实体数量。

- 阵列区域与导航位姿属于分开的标注步骤：先核实上游真实行为，不因缺少位姿便自动补造导航坐标或拓扑节点。旧工位补全须显式触发，保留稳定 ID、边界、编号及已有位姿位置朝向；依据有效引用复用位姿，多候选需明确选择，已有连线和自定义代价不覆盖。缺少可校验底图或可视拓扑时报告未连通，补全须可撤销、幂等并验证导出重开。
- 元素树的组合层级依据真实归属字段组织，不能依赖名称或空间接近；分页、搜索、视口外父项与草稿变更须保持一致。门的进出位姿归入对应门，缺失父项的旧记录保留可见与可编辑，不为界面分组迁移实体或新增存储结构。

- 显示按业务子类型判断，不能把共享存储类型等同于图层：工位与房间同为 region，但须依据 region_type / 轮廓 ws 分离。绘制、命中、关联线、悬浮过滤及三维显示复用同一可见性规则；文字开关与轮廓开关分开。新增图层偏好缺失时采用明确默认值，不能继承其他图层的关闭状态；显示变化不得迁移或改写实体。

- 元素树单击定位强调与属性编辑分开；组合选择以完整成员范围适配视口，不只使用当前分页或搜索结果。验证选择、缩放不产生草稿变更，删除与撤销仍有效，异步选择不得覆盖较新的画布操作。
- 栅格可通行性检查使用栅格自身的原点、分辨率和实际图像尺寸，不借用历史工程轮廓缓存的 map_meta。前端临时连线成功不能代替服务端规范化后的事实；覆盖两个坐标帧不同、负世界坐标、真实障碍、保存重开和 DB 导出的连接验证。不得以更改原地图坐标、豁免校验或穿墙最近连线修复误报；旧标注补连须显式、可撤销并保留既有有效连线及代价。

- 连线、断线等专用工具的端点命中不得直接受大面积位姿/门轮廓遮挡；优先可见节点中心并按屏幕距离判断，普通选择/拖动保持各自语义。覆盖不同缩放、创建顺序、中心重合、隐藏图层、连线/断线/撤销与保存重开；不能通过移动标注或修改真实占地尺寸绕过命中问题。

- 服务器收件目录必须固定范围，默认只读挂载；稳定性复查通过后复制到受管目录，不原地解压。用户明确授权成功后清理时，仅该收件卷允许写入；清理须独立于扫描，验证规范化产物、站内原始副本与原件完整哈希及身份，使用持久化暂存意图与不覆盖恢复，异常保留，无法确认时不虚报成功。收件身份、全内容去重、源记录和转换任务关联须持久化，覆盖复制中断、文件变化、重启、转换取消与重试；关闭定时发现不隐式取消已登记处理。原始数据规范化不得隐式启动建图，来源须与直接地图导入区分。

- 固定时刻任务须明确业务时区并持久化下一执行时间，手动操作与后台重试不推迟日程；首次迁移避免立即处理存量数据，中断后可恢复且跨进程不重复执行。紧凑设置采用即时保存时，须防止迟到读取覆盖新值，保存失败恢复已持久化状态；空态和单页不显示无效分页。

- 大文件规范化须从实际扫描与逐帧转换回传阶段、帧数、速度和估算时间，节流上报且不能伪造进度；无配对图像及非选择数据的读取过程也须响应取消。同机仅复用已校验受管文件并限制路径范围，保留跨文件系统下载回退。性能优化须保持帧、图像及位姿校验等价，区分微基准收益与完整任务耗时。

- 建图深度补全默认开启，完成深度输出上限为5米；原始深度保留上限独立可调。修改距离策略须同步实际融合、worker与底层脚本的下游范围、摘要和中英文界面，并以数值边界及关闭补全流程验证，不能只改文案。

- 地图视图旋转只改变相机投影，底图、语义、参考数据和选择叠加层使用一致变换；不能改写实体、朝向、草稿或导出坐标。命中和弹窗使用对应逆变换，视口取屏幕四角反投影包围框，适配按旋转外接尺寸。覆盖任意角度、绘制中保护、真实鼠标标注与保存导出重开。
- 中小地图可在记录数与传输字节双预算内完整驻留，超限回退视口加载；保留远端版本刷新、本机未发布编辑及大图分块行为。性能结论须记录真实地图规模、请求数和实际像素；缺失底图资产不能误判为加载延迟。建图卡区分总进度与阶段计数，速度和预计时间来自实测，计数长时间不变只能提示检查，不能虚构进度或自动取消。

- 原始 MCAP 与 metadata.yaml 配对上传作为一个采集输入，校验引用对应关系、保留元数据并支持单 MCAP；不能静默忽略多选文件。补充地图文件按已持久化父版本关联到原记录，不按名称猜测归属。
- 离线编辑入口从首个 HTML 即采用离线模式。连接列表刷新须检查各实际通道并统一排序，不以登记或旧缓存推断在线；SSH 静态查看不能冒充 Monitor 定位控制。
- 可视化健康必须检查数据协议握手，不能只检查 HTTP 页面或端口；恢复只操作监督器拥有的进程组，保留建图与录制，并让浏览器重新连接已恢复的服务。

- 旋转裁剪使用当前画布完整矩阵逆变换的四角范围，不能把矩阵 a 分量当作像素比例；回归覆盖正负各象限、90/180 度、高分屏及实体与连线实际像素，驻留数量不变不能替代绘制验证。

## 测试与验收

- 上传、导入等跨页面功能必须在隔离环境贯通真实页面、HTTP 接口、持久化、刷新重开及关联功能全流程，并覆盖取消、续传、失败重试和重复提交。依据实际变更选择相关回归；无关功能不重复运行耗时套件，发布的版本、依赖、锁和健康校验仍须执行。

- 为实际修改添加或更新定向单元、边界和必要的浏览器测试，覆盖确认、取消、失败重试及重复提交等相关路径。
- 缩放或拖动后元素消失的报告，先核对截图版本与当前线上版本；使用真实滚轮和拖动事件，在已知元素位置检查场景数量、图层偏好与实际像素，覆盖放大、缩小和高倍率。区分正常视野裁剪、加载完成后的镜头复位与场景丢失；已上线修复经验证有效时，不重复发布相同代码。
- “列表有、画布无”先分别核验实体记录、轮廓恢复、坐标/视口和持久化显示偏好，并保留具体版本与地图的只读复现证据。测试覆盖相关图层开关组合及旧偏好恢复，检查指定元素的实际描边/局部像素和真实鼠标命中；实体数量、全图网格像素或测试直接注入轮廓不能证明修复。测试夹具应包含被隐藏和仍应显示的子类型，不能用空对象固化整函数提前返回等错误实现。
- 涉及地图编辑或持久化时，在隔离副本中验证受影响的物体、房间、门、拓扑编辑，以及保存、重载、导入和导出一致性。未涉及的流程不虚报为已验证。
- 语义附属表也是地图产物：导出核心导航表时须保留已记录的场景帧、物体关系和审查证据，并按删除/合并后的实体标识同步引用。回归应实际重开导出 DB/数据包，检查帧记录与环境关系，不仅比较实体和边的数量。已有重算候选优先于旧基线，不能从邻近物体或近似时间补造丢失帧。
- 不默认运行批量压力测试、长时间建图或真实机器人写入。需要扩大测试范围、消耗大量资源时先说明影响。
- 使用低成本代理运行独立定向测试；实现者仍负责理解失败、核实证据及最终交付。报告实际通过项、失败项和未测项，不声称能够保证零缺陷。

## 版本发布与部署

- 当前任务要求发布时，使用 `mapdb-release-deploy` 技能的最新流程，不在本文复制易过期的部署脚本。用户明确要求仅本地时，不能创建远端发布或部署生产环境。
- 云端双卡生产目标为 `xchu@10.136.29.157`。禁止把旧 5090 服务器作为发布或失败回退目标；独立 GitLab Viewer 仓库不在修改范围内，云端适配应放在本项目所有的代码中。
- 发布前检查远端最新提交、明确文件白名单、完成规定测试和独立审查；保留已有数据挂载与同事提交。不覆盖脏工作树，不绕过并发发布锁和流水线门禁。
- 使用新的语义版本 tag，通常为下一 PATCH；禁止复用或强推已发布 tag。按流程维护中英文变更记录及中文通知摘要，并先校验通知内容。
- 优先复用经验证的依赖镜像；仅在依赖确有变化时按流程构建。不得为了单次前端修复无理由重装整套环境。
- 等待 tag 流水线完成，核对目标机器上的版本、提交、容器健康、两张 GPU 和关键页面。测试不删除生产地图或启动真实耗时任务。
- 交付说明应包含功能变化、测试证据、tag、部署结果及剩余限制。失败时报告阻塞和可恢复状态，不把创建 tag 等同于部署成功。
