# 可选新机安装流程

仅安装用户明确要求的软件。示例任务涉及飞书、RustDesk、Zotero、坚果云以及 GitHub 技能仓库；这些不是使用键盘技能的强制依赖。

1. 检查 /Applications、应用包标识、架构及本地化名称。Lark.app 的中文显示名可能就是飞书；不要仅凭英文包名重复安装。
2. 优先官方发布页和下载地址；Homebrew cask 元数据可帮助找包，但仍检查真实来源、当前版本和芯片架构。本机无 Homebrew 时不必为几个应用额外安装它。
3. 下载到临时目录，核对可用的 SHA-256；用 codesign、spctl 或 pkgutil 检查应用/安装包签名与公证。挂载 dmg 后按实际结构安装，避免覆盖已有应用。
4. 本案例坚果云在线安装器签名校验失败；没有运行它。读取安装器内的官方下载地址后，下载完整客户端并通过验证再安装。不要普遍绕过 Gatekeeper、移除签名或关闭安全检查。
5. RustDesk 等应用的屏幕录制、辅助功能、登录/同步授权由用户完成。安装完成不等于远程控制权限已就绪。
6. GitHub 技能仓库以当前分支内容为准；网页缓存可能落后。只将含有效 SKILL.md 的目录装入 skills，保留引用资源。不运行仓库中的部署脚本来“安装技能”。
7. Python/Git 可能只有 macOS 占位程序；先验证是否可运行。工具缺失时说明限制，不能把复制文件说成 git commit/push。

本次用安装包验证与应用路径确认安装结果；没有把用户登录、云同步、远程控制配置等未请求步骤算作完成。
